Scoring workings

Raw value → 0–100 score → weighted into its dimension

Method: revenue ramps on an S-curve from each route's first-revenue month to steady state (market size × target share × reach). Contribution is revenue × (gross margin − channel take); cash flow subtracts CAC on new and replacement customers, fixed costs and set-up. Breakeven past the horizon is projected at the final month's cash flow. Scores use fixed anchors, so one route's score never moves because another route changed. Same model as the open-source Python tool; the example figures are synthetic.
